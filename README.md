# 🚀 Piyush's 3D Developer Portfolio

Welcome to my personal portfolio! This is a modern, premium, and highly interactive 3D web application built to showcase my skills as a Python Developer and aspiring AI Engineer.

---

## ✨ Features
- **3D Interactive Background**: Custom particle starfield using React Three Fiber.
- **Glassmorphism UI**: Sleek, modern components with frosted glass effects and neon glows.
- **Smooth Animations**: Staggered reveals and scroll-triggered animations powered by Framer Motion.
- **Fully Responsive**: Flawless experience across mobile, tablet, and desktop devices.
- **Working Contact Form**: Integrated with FormSubmit for real-time messaging, protected by built-in CAPTCHA.
- **Easy to Update**: All content is managed from a single data file, making updates effortless.

---

## 🛠️ Tech Stack
- **Frontend Framework**: React.js, Vite
- **Styling**: Tailwind CSS
- **3D Rendering**: Three.js, React Three Fiber, @react-three/drei
- **Animations**: Framer Motion
- **Icons**: React Icons

## 🍼 Beginner's Guide: How to Run This Project

If you are new to web development, don't worry! Follow these simple steps to get this portfolio running on your own computer.

### Step 1: Install Prerequisites
Before you start, you need two things installed on your computer:
1. [Node.js](https://nodejs.org/) (Download the "LTS" version and install it like a normal program).
2. [Git](https://git-scm.com/downloads) (Required to download the code).

### Step 2: Download the Code
Open your terminal (Command Prompt or PowerShell on Windows, Terminal on Mac) and run:
```bash
git clone https://github.com/student-piyush25/portfolio.git
```

### Step 3: Open the Project
Navigate into the newly created folder:
```bash
cd portfolio
```

### Step 4: Install Dependencies
This project uses several libraries (like React and Tailwind). Tell Node.js to download them all by running:
```bash
npm install
```
*(This might take a minute or two)*

### Step 5: Start the Website!
Run the following command to start the local development server:
```bash
npm run dev
```
You will see a link in your terminal (usually `http://localhost:5173` or `http://localhost:5174`). Hold the `Ctrl` key and click that link, or copy and paste it into your web browser. Boom! Your 3D portfolio is now running locally.
